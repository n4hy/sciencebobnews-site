# Science Bob News — site repo

This repository hosts the **rendered output** of the [Science Bob News](https://github.com/n4hy/ScienceBobNews) UAP / UFO / USO news fusion engine. It is not a place where humans commit code; it is an outbound landing pad. The engine runs elsewhere, builds a static SITREP, and pushes the finished files here. GitHub Pages then serves them at:

**🌐 https://n4hy.github.io/sciencebobnews-site/**

---

## What's in here

| File | Source | Refreshed |
|---|---|---|
| `index.html` | Generated by `render_html` in the engine | When the SITREP content changes |
| `sitrep.md` | Generated by `render_markdown` | When the SITREP content changes |
| `feed.json` | Generated by `render_feed` (machine-readable) | When the SITREP content changes |
| `card_c_{n}.svg` | One card per **corroborated** story this cycle (absent when the lane is empty) | When those stories change |
| `card_d_{n}.svg` | One card per **developing** or **podcast** story this cycle | When those stories change |
| `LICENSE` | Copied from the engine each publish | Static text; re-copied so the page link resolves |
| `banner_*.svg` | Original section banners (currently unused on the rendered article, kept for future reuse) | Static |

Every story card is a **self-contained SVG** composed from that story's headline + Admiralty reliability rating + source count + platform list. No third-party imagery, no hotlinked thumbnails, no re-hosted media. Browsers will not load external `<image href>` resources inside an SVG used as `<img>`, so the public cards do not reference YouTube (or any other) CDNs.

PNG card rasters are generated on the build host for the operator's X Article paste path. They are **not** committed here.

## How the data path works

```
Bluesky firehose ─┐
Mastodon tags ────┼─► engine clusters → BitNet reliability scoring
9 podcast YT RSS ─┘                              │
                                                 ▼
                                       build/public/ on the build host
                                                 │
                                                 ▼  outbound git push
                                       this repo  ─► GitHub Pages CDN
                                                 │
                                                 ▼
                                       https://n4hy.github.io/sciencebobnews-site/
```

The build host runs the engine via cron:

- `*/10 * * * *` — full SITREP build, push here if content changed, broadcast on Bluesky + Mastodon
- `0 * * * *` — video-only SITREP, broadcast podcast video links
- `*/30 * * * *` — copy `article.md` (X Article-ready markdown) to the operator's clipboard and notify

The build is intentionally **outbound-only**: the build host opens no inbound ports and runs no web server. It pushes finished files here; GitHub serves them.

## How a fresh SITREP appears here

Each cycle the engine:

1. Pulls public free sources (no API keys): Bluesky's public firehose, Mastodon hashtag timelines, and YouTube RSS feeds for the tracked podcasts (Need to Know · Theories of Everything · Weaponized · Project Unity · American Alchemy · Area 52 · Orbis Paranormal · Fade to Black · Spaced Out Radio).
2. Runs the UAP topic gate.
3. Clusters social-feed posts to count *independent* corroboration. Podcast episodes bypass clustering so each episode is its own story.
4. Scores each event (heuristic Admiralty, or BitNet when `--learned-scorer` is on), then **clamps** the rating: digit `1` requires independent corroboration; a single-source podcast cannot be A1 / P(credible)=1.0.
5. Writes `index.html`, `sitrep.md`, `feed.json`, `LICENSE`, and one self-contained card SVG per story in this cycle. Leftover cards from the previous mix are deleted.
6. Commits and pushes **only if the stories changed**. A cycle that only bumps `generated_utc` is not published.

## Lanes

| Lane in `feed.json` | On the page | Meaning |
|---|---|---|
| `corroborated` | Corroborated | Independent multi-source (or official) items |
| `developing` | Developing / unconfirmed | Social-feed items not yet independently confirmed |
| `podcast` | Disclosure podcasts | Tracked YouTube episodes; headline is the **episode title**; source handle is the show |

Reliability ratings are automated, not editorial. Science Bob News makes no claim that any flagged report is authentic; it credits sources, links originals, scores corroboration, and flags likely fakes and prosaic explanations so readers can judge.

## Where the code lives

Engine, publisher, RSS adapters, BitNet trainer, X-Article notifier, and the card SVG generator are all in the sibling repo: **[github.com/n4hy/ScienceBobNews](https://github.com/n4hy/ScienceBobNews)**.

If you want to read the renderer that produced any file in this repo, the corresponding function is in `science_bob_news.py` there:

| File you see | Function that built it |
|---|---|
| `index.html` | `render_html(confirmed, developing, ts)` |
| `sitrep.md` | `render_markdown(...)` |
| `feed.json` | `render_feed(...)` |
| `card_*.svg` | `make_story_card_svg(story, kind)` |
| `LICENSE` | copied by `publish.stage` |
| `article.md` (not committed here — operator-only) | `render_article(...)` |
